## Historical state and source selection

The October 2 commerce handoff identifies the eCommerce validation SPI as published with validateInCart enabled and an ERROR violation. This repository retains the 1,126-byte combined five-language notice version from that handoff. A separate 1,751-byte language-context draft was found and omitted because it is not the version included in the later published handoff.

The October 7 verification records saved draft **391 as not published**, with published revision **387** last observed at 18:28 HKT on October 6. Draft 391 recorded three native UI changes: removing mobile Hero entrance animations, applying a gentle native mouse-tracking effect to an existing decoration, and changing the existing Japan CTA hover border to white. These are native Wix settings, not newly recovered page code.

A later October 7 file instructs how to finish release checks and conditionally publish. It does not record a completed publication. Read the historical documents as a handoff, then establish the current Wix state before making site changes.

The historical preview scope keeps product browsing, adding to Cart and Cart available while payment and real ordering remain closed. Copying these materials does not change any Wix settings.

## Working with these materials

- Use the manifest to distinguish exact source copies from sanitized or summarized evidence.
- Keep the existing branding and visual work. No replacement website or layout is generated by this repository.
- Before modifying or redeploying the historical validator, compare it with the current supported Wix backend source and current business requirements.
- Inspect current native Wix history before restoring or publishing. Historical revisions must not overwrite newer owner work.
- Record new verified changes and tests separately from the historical October 2 and October 7 observations.

## Assets and excluded private material

The logo and banner are existing KeEv project assets recovered from the owner's saved files. Their presence does not grant a new third-party license. No unverified font bundle or unrelated reference-image collection is included.

Private feedback links, editor/admin links, raw authenticated screenshots or recordings, browser sessions, credentials, customer information and unrelated accounting data are excluded. The raw ZIP evidence packs remain outside this public companion repository.

No Wix or GitHub deployment was performed as part of this recovery.
