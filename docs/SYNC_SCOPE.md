# Synchronization scope

## What this repository makes available

The repository carries the recovered Velo validation snapshot, selected existing brand assets, sanitized historical evidence and the shared project state. Once committed to GitHub, these repository files can be retrieved from another authorized computer or coding environment.

This is a repository handoff. It does not merge ChatGPT or Codex conversation histories, copy a computer's entire working directory, preserve browser login sessions, or make uncommitted local files available elsewhere. Record important decisions and progress in PROJECT_STATE.md and commit the relevant files so another session has a concrete starting point.

## What stays outside this repository

| Material or capability | Status |
| --- | --- |
| Complete Classic Editor visual page/layout model | Not present |
| Current native Velo source tree | Not retrieved; historical validator snapshot only |
| Native Wix–GitHub integration | Unverified; not connected or changed by this task |
| Automatic ongoing file synchronization | Not configured or demonstrated by this task |
| Wix deployment from a repository push | Not configured by this task; a push is not evidence of site publication |
| Raw browser sessions, private feedback links and authenticated screenshots | Excluded |
| Complete operational store backup, customer/order/member records | Excluded |

The site's current metadata says it is published, uses Editor / Classic Wix Editor, and has Velo enabled. Those fields establish none of the missing integration/export capabilities in the table.

## Current-state checks versus recovered history

PROJECT_STATE.md records the current-session metadata separately from the October 2 source snapshot and October 7 draft evidence. The Wix-reported last-updated value of 7 October 2026, 00:14 has no supplied timezone. It must not be treated as proof of when a specific draft was published.

Before future native Wix work, use the current authorized session to identify the relevant actual site state. Before future Git integration work, inspect the actual Editor connection and supported setup; do not rename/delete the requested GitHub repository or connect another site based only on assumptions.

The repository's checksum list verifies repository-file contents. It does not verify the live site, its current revision, or live backend code.
